YOUTUBE DESCRIPTION — FULL VIDEO
==========================================

An average hides the story. Two plants can both score 70 on average while one is predictable and the other swings from 30 to 95. Box & Whisker by TCViz shows how the values of each category are spread: the median, the middle half of the values, how far the normal range reaches and which cases fall outside it. Power BI has no built-in box plot.

Get it on Microsoft AppSource: https://marketplace.microsoft.com/en-us/product/tino_callarisa.box-whisker-tcviz

──────────────────────────────────────────
WHAT IT DOES
──────────────────────────────────────────
✅ One box per category: median, first and third quartile, whiskers and outliers
✅ n under every box, so a box built on 12 rows is not mistaken for one built on 12,000
✅ Whiskers at 1.5 × IQR (Tukey) or minimum to maximum
✅ Quartiles with the inclusive method, the same as Excel QUARTILE.INC, named in every tooltip
✅ Vertical or horizontal; six style templates, including an IBCS style
✅ Click a box to filter the report; bookmarks, drilldown, keyboard navigation and high contrast
✅ The measure's number format and the report language; twelve languages
✅ No network requests: every statistic is computed inside your report

Useful in quality, operations, HR, service and sales: anywhere the question is "how consistent is it?", not only "how much on average?".

──────────────────────────────────────────
FREE AND PRO

FREE — a complete box plot:
