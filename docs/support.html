A box plot that reads well: median, quartiles, whiskers and outliers for each category, with n on every box and the quartile method stated. The free version is a complete box plot. Pro adds points with jitter, mean and notches, violin, groups and small multiples, sorting by median, reference lines and a statistics table.

Quick Start

  1. Add Box & Whisker by TCViz to the page. With no fields it shows a start screen with these steps.
  2. Drag the field that defines the boxes to Category — region, product, team.
  3. Drag the measure to study to Value — days, amount, score.
  4. Drag the ID of each row to Detail (rows) — order, employee, ticket.
  5. Pro: add a Group or Small multiples field, turn on points, violin or the statistics table.

How to read it

Box: the middle half of the values, from Q1 (25th percentile) to Q3 (75th). Line inside: the median. Whiskers: up to the last value still considered normal (by default within 1.5 × the box height). Dots beyond the whiskers: outliers. n: the number of rows behind the box.

If the median is not centred in the box, the values are skewed towards the longer side. A tall box means a spread-out, less predictable result; a short box, a consistent one. Compare medians to see which category is higher, and box heights to see which is more stable. With very few values (under about 10 per box), turn on all points (Pro) to see each one.

Selection and interaction

  • Click a box to filter the rest of the page by its category (and group or panel); Ctrl/Cmd + click to add more; click it again or click the background to clear.
  • A selected box keeps every row of the category: a card next to it shows the full count.
  • Bookmarks restore the selected boxes. Right-click opens the Power BI context menu. A hierarchy in Category gives drilldown.
  • When the report author turns interactions off, clicks do not filter.

Accessibility

  • Keyboard: Tab into the visual, arrows move between boxes, Home/End jump to the first/last box, Enter or Space selects, Esc clears, the context-menu key opens the menu. The tooltip opens on the focused box.
  • Each box has a description for screen readers with its median, quartiles and n.
  • High contrast: the visual uses the colours of the Windows contrast theme.
  • The layout adapts to the size of the visual: axes, n labels and legend give way before the boxes do; the legend shows the groups that fit, and the start screen has three layouts.

FAQ

How do I read a box?

The box holds the middle 50 % of the values, from the first quartile (Q1) to the third (Q3). The line inside is the median. The whiskers reach the last value that is still considered normal, and the dots beyond them are outliers. n under the box is the number of rows behind it.

What do the whiskers show, exactly?

With 1.5 × IQR (Tukey), the default, each whisker goes to the last value within 1.5 times the height of the box (Q3 − Q1) from the box. Anything beyond is an outlier. Minimum to maximum draws the full range and no outliers. The percentile options (Pro) end the whiskers at the 5th/95th or 10th/90th percentile, which reads as "90 % of cases are between…".

Why are my quartiles different from Excel or from another tool?

There are several accepted ways to compute quartiles and they differ with few rows. The default is the inclusive method, the same as Excel QUARTILE.INC and PERCENTILE.INC. Pro adds Excel QUARTILE.EXC and Tukey hinges. The method in use is shown in every tooltip.

Each box shows n = 1, or the boxes are flat

Add the ID of each observation to Detail (rows). Without it Power BI aggregates the value to one number per category and there is nothing to distribute. The visual shows a note when Detail is empty.

Should Value be Sum or Average?

With one row per ID in Detail, both give the same number per row. Use the aggregation that makes sense if an ID can have several rows.

How many rows can it use?

Power BI sends the visual up to 30,000 rows at a time. In the Power BI service the visual asks for further blocks automatically, up to 40 more (about 1.2 million rows). In Power BI Desktop the visual uses the first 30,000 rows and does not request more. In both cases a warning icon in the visual header says how many rows were used when some were left out. Statistics always use every row received. With all points shown, up to about 4,000 points per box are drawn; the violin's density is estimated from up to 2,000 values per box.

Do bookmarks keep my settings?

Bookmarks keep the boxes you select and the filters of the page. Like every Power BI visual, they do not keep formatting such as orientation or points. To switch between two looks, use two copies of the visual and show one or the other in each bookmark.

What is the "Pro preview" watermark?

While you edit a report without a licence, Pro features you turn on are drawn working under a watermark that names them, and Power BI shows its licence notice. Reading view shows the free result, with a small note naming the Pro features it leaves out. Nothing is lost: the settings apply as soon as a licence is active. Where Power BI provides no licence information (for example when you are not signed in to Power BI Desktop), the free result is shown and there is no preview.

How do I get Pro?

On the visual's Microsoft AppSource page, choose Buy now (not Install free). Licences are per user and managed by Microsoft; restart Power BI Desktop after the licence is assigned. See tcviz.com/licensing.

How are numbers formatted?

With the measure's number format from the model, dynamic format strings included, in the report's language. Statistics that are not whole numbers (mean, interpolated quartiles, standard deviation) show up to two decimals when the format has none.

Is my data sent anywhere?

No. The visual makes no network requests and stores nothing outside your report. The links on the start screen open only when you click them, through Power BI.
